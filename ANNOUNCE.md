# Анонс портфолио для Telegram-канала

---

**🚀 Собрал портфолио: 19 репозиториев AI-прототипов — от идеи до работающего сервиса**

Позиционирую себя как AI вайб-кодер и прототипист: довожу MVP самостоятельно, с Cursor, ChatGPT, OpenRouter и другими LLM. Формула простая: идея → промпт → рабочий код → отладка → работающий сервис.

**Что внутри:**

🛒 **Smart Shopper** — «ChatGPT для маркетплейсов»: поиск по тексту и фото через LLM, grounding только на реальные данные Ozon / Яндекс Маркета / WB. Telegram-бот + Mini App на React
📊 **Ozon Seller Bot** — MVP для продавцов с полным роадмапом 5/5: сводка магазина, алерты «товар закончился» и падения цены, график выручки, FBS-отправления. Работает без ключей в демо-режиме
💰 **Finance Bot** — фото чека читают локальная Vision-модель (Ollama) и Tesseract, победитель выбирается по арифметике
⚖️ **Marketplace Price Compare** — сравнение цен трёх маркетплейсов параллельным поиском + watch-подписки на снижение
⭐ **AI Review Analyst · Stars Payment Gateway · Paint by Numbers** — анализ отзывов LLM, платный доступ через Telegram Stars, и раскраска по номерам с живым демо

**Как это сделано:**
— CI на каждый пуш в 14 проектах, зелёные бейджи в README
— детерминированные демо-режимы: любой проект запускается без API-ключей
— OG-превью у всех репозиториев, двуязычный лендинг с фильтрами по стеку
