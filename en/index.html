⚡ How I work

1. Idea and scope. Define the product, the audience and the smallest slice that proves value. Cap the first prototype at one week.

2. Architecture with LLMs. Have the model draft structure, data schemas and risks; argue with it and lock decisions before the first line of code.

3. Vibe coding. Small iterations in Cursor/ChatGPT: prompt → diff → run it immediately. Logic that must not be trusted blindly (money, APIs) goes under tests.

4. Debugging and hardening. Read AI-generated code like a code review: boundaries, errors, races. Rewrite the weak spots — speed without control is worth nothing.

5. CI and demo mode. A workflow on every push, deterministic demo data with zero secrets, so any project can be shown and run without keys.

6. MVP to production. Real keys, a real user, feedback — and the next step driven by it, not by imagination.
